[b]Fair Duelist - Customizable Difficulty[/b]

Choose and confirm Story, Fair, Challenging or Duelist in the game settings, then open Mod Settings to customize absolute enemy health, damage, stamina costs and attack delays. 100% means the unscaled game value; 50% is half and 150% is one and a half times. Lower attack-delay percentages allow more frequent attacks.

Confirming a difficulty in the game's settings resets the corresponding values; canceled previews preserve saved balance. The game retains its original difficulty names. Outdated or invalid settings reset to current defaults.

[b]Installation[/b]

Requires UE4SS and Mod Setting Menu 1.0.5.1. Replace the existing Fair Duelist entry through Vortex. The mod uses the original Mod Setting Menu without replacing its files. For an old asset-based installation, disable and deploy it before installing the replacement so Vortex removes its old containers. Restart, load a save once, then configure the mod in Mod Settings. Apply, then load a save. Back up generated settings.ini before reinstalling or uninstalling. See the included README and SETTINGS.md for complete instructions.

[b]Configuration[/b]

Enemy health, enemy damage and combat stamina cost use absolute percentages. Three attack-delay controls set normal, low-health and ranged attack cooldowns. A separate switch controls attacks while another enemy blocks. Animation speed, parry windows and other native game options follow the game's difficulty settings. Logging is the final setting and the only diagnostic control.

[b]Compatibility and credits[/b]
